3. Google Cloud Platform (GCP) Architecture

Enterprise Cloud Infrastructure

The entire backend and data pipeline runs autonomously on Google Cloud Platform:

  • LLM Inference: Google Vertex AI (gemini-2.5-flash) in project nuveroai (us-central1).
  • Container Execution: Google Cloud Run serverless container with automated horizontal autoscaling.
  • Multi-Day Session Store: Persistent memory keyed by user_id / phone number for seamless WhatsApp API multi-day persistence.
  • Cloud Storage: All student profile records and indexed RAG embeddings reside in cloud storage.
